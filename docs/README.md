## Status

The Manifesto is published and unchanged. Part A and Part B of the Founding Book are complete working drafts. The Charter is a draft derived from the Founding Book. Essentia v0.1.0 is runnable research software for a narrow ledger experiment; v0.8.0 is the current research architecture and is not implemented. No currency, Freedom Floor, civic identity, binding voting, or benefit system is live.
